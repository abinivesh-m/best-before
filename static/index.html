How the score is built

Each claim gets three readings. They are combined with fixed weights, so you can see exactly why something was flagged.

0.60

Agreement

Do the sources state the same value, a different one, or nothing at all? Contradictions from official documentation carry the most weight.

0.25

Recency

Publication dates decay on a half-life set by claim type: weeks for pricing, months for versions, a year for regulation.

0.15

Authority

Primary documentation outranks vendor blogs, which outrank press, which outranks forums. The domain tier is shown on every source.
